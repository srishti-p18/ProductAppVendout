# React Native Product App

## Features
- List of products with images, prices, and descriptions
- Tap to view full product details
- Buy Now button with placeholder alert
- Search functionality
- Styled using React Native components

## Setup Instructions

1. Clone the repo:
```bash
git clone https://github.com/srishti-p18/ProductAppVendout.git

Navigate to the project directory:
cd ProductAppVendout

Install dependencies:

npm install

Start the development server:

npx expo start

Dependencies
React Navigation
React Native Context API
Expo (for ease of development)
